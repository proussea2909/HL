# Vendored skills: story-skills

The skill directories in this folder are vendored from the open-source
**story-skills** project:

- Source: https://github.com/danjdewhurst/story-skills
- Commit: c482d48
- Author: Daniel Dewhurst
- License: MIT (see `LICENSE` in this directory)

These are unmodified copies of the upstream `skills/` directory, placed here so
they are available automatically in every Claude Code session for this repo.

## Skills included

| Skill | Purpose |
| --- | --- |
| `story-init` | Initialize a new fiction writing project |
| `worldbuilding` | Develop settings, locations, systems, factions |
| `character-management` | Create and track characters and relationships |
| `plot-structure` | Plan narrative structure, arcs, foreshadowing |
| `chapter-writing` | Draft chapters and scenes via outline-first workflow |
| `revision-continuity` | Revise prose and audit continuity |
| `story-maintenance` | Deterministic validation/maintenance (CLI in `scripts/`) |

To update, re-clone the upstream repo and copy `skills/` over this directory.
